# טקסט מוכן להעתקה ל-Google Forms

פתח/י טופס Google Forms חדש והעתיקי כל שאלה כמו שהיא (שם השאלה + סוג שאלה
מוצע + אפשרויות). מקומות עם [ ] למילוי ידני שלך.

---

**כותרת הטופס:**
```
הרשמה למיני-קורס: מקורות חיים גנריים לקורות חיים שמקבלים ראיונות
```

**תיאור הטופס (מתחת לכותרת):**
```
מיני-קורס בזום, 3 מפגשים קצרים (כ-60-70 דקות כל אחד), פעמיים בשבוע,
בעברית — לומדים להשתמש ב-AI (ChatGPT חינמי) כדי לכתוב תקציר מקצועי,
נקודות ניסיון עם תוצאות מדידות, ומכתב מקדים מותאם אישית למשרה אמיתית.
מספר מקומות מוגבל.

תאריכים ושעות שלושת המפגשים: [למלא — כולל אזור זמן, למשל
"20:00 לפי שעון ישראל"]
עלות: 50 € לכל הקורס (לא לכל מפגש)
```

---

### שאלה 1
**סוג:** תשובה קצרה | **חובה:** כן
```
שם מלא
```

### שאלה 2
**סוג:** תשובה קצרה | **חובה:** כן
```
טלפון (לתזכורת וואטסאפ יום לפני כל מפגש)
```

### שאלה 3
**סוג:** תשובה קצרה | **חובה:** כן
```
אימייל (לשליחת קישורי הזום והחומרים)
```

### שאלה 4
**סוג:** בחירה מרובה | **חובה:** לא
```
גיל
```
אפשרויות: `20-25` / `26-30` / `31-35` / `36-40` / `אחר`

### שאלה 5
**סוג:** תשובה קצרה | **חובה:** כן
```
באיזו מדינה ובאיזה אזור זמן אתה/את נמצא/ת? (חשוב כדי לוודא ששעות שלושת המפגשים מתאימות לך)
```

### שאלה 6
**סוג:** בחירה מרובה | **חובה:** לא
```
האם יש לך היום קורות חיים קיימים שתביא/י למפגש הראשון?
```
אפשרויות: `כן, יש לי גרסה קיימת` / `לא, אכין משהו בסיסי לפני` / `לא בטוח/ה`

### שאלה 7
**סוג:** בחירה מרובה | **חובה:** לא
```
שפת העדפה לחומרי הקורס
```
אפשרויות: `עברית` / `אנגלית` / `לא משנה לי`

### שאלה 8
**סוג:** פסקה (תשובה ארוכה) | **חובה:** לא
```
אם היינו מריצים סדרת מיני-קורסים על נושאים נוספים בעתיד (כל אחד בתשלום, 2-3 מפגשים) — אילו נושאים היו הכי מעניינים אותך?
```

### שאלה 9
**סוג:** תשובה קצרה | **חובה:** כן
```
אישור תשלום: שילמת/י 50 € דרך [PayPal / העברה בנקאית] עבור כל 3 המפגשים? נא לציין את מספר/פרטי האסמכתא כאן
```

### שאלה 10
**סוג:** תיבת סימון (checkbox) | **חובה:** כן
```
קראתי והבנתי שמדובר בקורס בתשלום מראש עבור 3 מפגשים, ללא החזר חלקי במקרה של אי-הגעה למפגש בודד ללא הודעה מראש
```
אפשרות יחידה לסימון: `מאשר/ת`

```
📅 מפגש 3: [תאריך ושעה + אזור זמן]

לפני מפגש 3, תוסיף/י גם:
3. מודעת דרושים אמיתית שמעניינת אותך (קישור או העתק טקסט) — נשתמש בה בתרגול האחרון.

```

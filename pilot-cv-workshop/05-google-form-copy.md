# טקסט מוכן להעתקה ל-Google Forms

פתח/י טופס Google Forms חדש והעתיקי כל שאלה כמו שהיא (שם השאלה + סוג שאלה
מוצע + אפשרויות). מקומות עם [ ] למילוי ידני שלך.

---

**כותרת הטופס:**
```
הרשמה לסדנה: מקורות חיים גנריים לקורות חיים שמקבלים ראיונות
```

**תיאור הטופס (מתחת לכותרת):**
```
סדנה חד-פעמית בזום, 90 דקות, בעברית — לומדים להשתמש ב-AI (ChatGPT חינמי)
כדי לכתוב תקציר מקצועי, נקודות ניסיון עם תוצאות מדידות, ומכתב מקדים
מותאם אישית למשרה אמיתית. מספר מקומות מוגבל.

תאריך ושעה: [למלא — כולל אזור זמן, למשל "20:00 לפי שעון ישראל"]
עלות: [XX] €
```

---

### שאלה 1
**סוג:** תשובה קצרה | **חובה:** כן
```
שם מלא
```

### שאלה 2
**סוג:** תשובה קצרה | **חובה:** כן
```
טלפון (לתזכורת וואטסאפ יום לפני הסדנה)
```

### שאלה 3
**סוג:** תשובה קצרה | **חובה:** כן
```
אימייל (לשליחת קישור הזום והחומרים)
```

### שאלה 4
**סוג:** בחירה מרובה | **חובה:** לא
```
גיל
```
אפשרויות: `20-25` / `26-30` / `31-35` / `36-40` / `אחר`

### שאלה 5
**סוג:** תשובה קצרה | **חובה:** כן
```
באיזו מדינה ובאיזה אזור זמן אתה/את נמצא/ת? (חשוב כדי לוודא שהשעה שנקבעה מתאימה לך)
```

### שאלה 6
**סוג:** בחירה מרובה | **חובה:** לא
```
האם יש לך היום קורות חיים קיימים שתביא/י לסדנה?
```
אפשרויות: `כן, יש לי גרסה קיימת` / `לא, אכין משהו בסיסי לפני` / `לא בטוח/ה`

### שאלה 7
**סוג:** בחירה מרובה | **חובה:** לא
```
שפת העדפה לחומרי הסדנה
```
אפשרויות: `עברית` / `אנגלית` / `לא משנה לי`

### שאלה 8
**סוג:** פסקה (תשובה ארוכה) | **חובה:** לא
```
אם היינו מריצים סדרת סדנאות נושאים נוספים בעתיד (כל אחת בתשלום, מפגש נפרד) — אילו נושאים היו הכי מעניינים אותך?
```

### שאלה 9
**סוג:** תשובה קצרה | **חובה:** כן
```
אישור תשלום: שילמת/י [XX] € דרך [PayPal / העברה בנקאית]? נא לציין את מספר/פרטי האסמכתא כאן
```

### שאלה 10
**סוג:** תיבת סימון (checkbox) | **חובה:** כן
```
קראתי והבנתי שמדובר במפגש בתשלום, ללא החזר במקרה של אי-הגעה ללא הודעה מראש
```
אפשרות יחידה לסימון: `מאשר/ת`

---

## הודעת אישור (לשליחה ידנית אחרי אימות התשלום)

```
היי [שם]!
נרשמת בהצלחה לסדנה "מקורות חיים גנריים לקורות חיים שמקבלים ראיונות".

📅 [תאריך ושעה + אזור זמן]
🔗 קישור לזום: [קישור]

לפני הסדנה, תכין/י:
1. קורות חיים קיימים שלך (גם גרסה ישנה/לא מושלמת) — קובץ Word/PDF או פשוט טקסט.
2. מודעת דרושים אמיתית שמעניינת אותך (קישור או העתק טקסט) — נשתמש בה בתרגול האחרון.
3. חשבון ChatGPT חינמי פתוח מראש: https://chat.openai.com

נתראה בקרוב!
```
